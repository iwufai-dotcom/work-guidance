# work-guidance

从 GPT6 的实际协作经验中整理出的通用工作行为引导，封装为可手动调用的 Codex Skill。

在复杂任务中，模型有时会持续增加解释、限定、检查和记录，却没有把专业判断落实成好用的成果。这个 Skill 希望改善这种工作倾向：保持用户的完整委托，主动承担构思、取舍、组织和实现，根据对当前目标的预期贡献与整体成本安排投入，让反馈真正改变后续行动，并依据实际成果判断继续、调整或交付。

引导保留探索与专业自主的空间，允许尝试失败，无需逐动作提交价值论证。它作为工作决策依据使用，本轮明确的用途、范围、交付阶段和资源条件优先。

下载并解压 [work-guidance.zip](work-guidance.zip)，将其中的 `work-guidance` 文件夹放入 `~/.codex/skills/`。在 Codex 对话中输入 `$work-guidance` 即可手动调用；当前配置仅允许显式调用。
